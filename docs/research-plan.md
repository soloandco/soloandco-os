# Research plan before v1

Interview at least five users in each segment:

- solo founders
- freelancers
- management agencies or studios

For each segment, observe a recent real workflow rather than collecting feature requests. Validate terminology, sensitive-data boundaries, CLI usability, generated-folder usage, and update expectations.

Minimum v1 evidence:

- 80% choose the correct preset without help
- 80% generate a workspace and record one real item within ten minutes
- at least half of generated core folders remain in use after two weeks
- zero production personal data in public fixtures or export results
- Windows, macOS, and Linux tests pass

Technical alternatives to compare:

- GitHub template repository for zero-install copying
- Node initializer for preset and module selection
- Copier when template-to-project updates become a validated need
